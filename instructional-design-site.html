Build roadmap

Phase 1 — Define the contract

Create docs/INSTRUCTIONAL-DESIGN-SPEC.md with required arc, mandatory checks/supports, mastery evidence, accessibility minimums.

Phase 2 — Enforce quality

Extend validator rules so missing instructional artifacts (checks/support layers for assessed sections) are flagged early.

Phase 3 — Prove with Episode 2

Implement full Episode 2 lesson flow with explicit objective-assessment traceability + remediation path.

Phase 4 — Iterate with data

Adopt an event taxonomy (misconceptions/retries/hint usage/language toggles) and run recurring instructional review.
